AIRLINE LOGOS
=============
Put an airline's logo in this folder and FlightScout shows it to the left of the airline name.
No code changes needed. Restart the server (Ctrl+C, then npm.cmd start) after adding files.

File names (lower case, spaces become dashes, .svg or .png):
  air-peace.svg      ibom-air.png       united-nigeria.png
  valuejet.svg       overland-airways.png   arik-air.png     xejet.png

Until a logo is added, FlightScout shows a small coloured badge with the airline's initials.

IMPORTANT FOR THE HACKATHON
Airline logos are trademarks. The Devpost rules say your demo video must not show third-party
trademarks without permission. Only add a logo if you have permission to use it (for example,
the airline gave it to you, or its brand page allows partner use). If you are unsure, leave the
folder empty and keep the initials badges.
